# ClanCoC Bot

ربات تلگرام حرفه‌ای برای مدیریت وارهای کلن Clash of Clans.

- پایش خودکار وار معمولی و CWL
- اعلان‌های گروهی (پیدا شدن حریف، آماده‌سازی، شروع نبرد، نتیجه)
- لینک Many-to-Many بین کاربران تلگرام و اکانت‌های کلش
- دستورات اونر برای مدیریت لینک دیگران
- دیتابیس Neon PostgreSQL
- API فقط از طریق پروکسی RoyaleAPI

## پیش‌نیازها

- Node.js 18+
- حساب توسعه‌دهنده Clash of Clans و توکن API
- دیتابیس Neon PostgreSQL
- ربات تلگرام ساخته‌شده با BotFather
- هاست Botkeep (یا هر محیط Node.js)

## متغیرهای محیطی

فایل `.env.example` را کپی کنید و مقادیر واقعی را تنظیم کنید.

| متغیر | توضیح | الزامی |
|-------|-------|--------|
| `BOT_TOKEN` | توکن ربات تلگرام | بله |
| `DATABASE_URL` | رشته اتصال Neon PostgreSQL | بله |
| `CLASH_API_TOKEN` | توکن API کلش (با IP پروکسی وایت‌لیست شده) | بله |
| `CLASH_API_BASE_URL` | پیش‌فرض: `https://cocproxy.royaleapi.dev/v1` | خیر |
| `OWNER_TELEGRAM_ID` | شناسه عددی تلگرام صاحب ربات | بله |
| `TELEGRAM_GROUP_ID` | شناسه گروه برای اعلان‌ها (منفی برای سوپرگروه) | توصیه می‌شود |
| `CLAN_TAG` | تگ کلن شما (با یا بدون #) | بله |
| `WAR_POLL_INTERVAL_MS` | فاصله بررسی وار (میلی‌ثانیه)، پیش‌فرض 120000 | خیر |

### تنظیم توکن کلش برای پروکسی

1. به developer.clashofclans.com بروید.
2. یک کلید جدید بسازید و IP زیر را وایت‌لیست کنید: `45.79.218.79`
3. توکن تولیدشده را در `CLASH_API_TOKEN` قرار دهید.

## نصب و اجرا

```bash
npm install
npm start
```

با اجرای `npm start` جداول دیتابیس ساخته می‌شوند، ربات به تلگرام متصل می‌شود و مانیتور وار شروع به کار می‌کند.

### روی Botkeep

1. ریپازیتوری را به Botkeep متصل کنید.
2. Start Command: `npm start`
3. تمام Environment Variables را در پنل اضافه کنید.
4. Deploy.

## دستورات

- `/start` `/help` `/war` `/clan`
- `/link #TAG` — لینک برای خود
- `/link TELEGRAM_ID #TAG` — لینک برای دیگران (فقط اونر)
- `/myaccounts` `/unlink` `/unlinkall`

## قابلیت‌های پیاده‌سازی‌شده

- اتصال تلگرام + Telegraf
- Environment Variables کامل
- Neon PostgreSQL + Many-to-Many + جلوگیری از اعلان تکراری
- Migration خودکار
- API فقط از cocproxy.royaleapi.dev + Retry
- پایش وار معمولی و پشتیبانی اولیه CWL
- اعلان حریف + لیست اعضا با لینک تلگرام قابل کلیک
- اعلان آماده‌سازی، شروع نبرد، پایان وار
- لینک چنداکانتی و دستورات اونر
- Escape امن HTML

## محدودیت‌ها

- گزارش لحظه‌ای هر حمله تکی ممکن است ناقص باشد (محدودیت API)
- پشتیبانی CWL بهترین‌تلاش است
- فاصله polling کمتر از ۱ دقیقه توصیه نمی‌شود
